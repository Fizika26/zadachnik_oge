# Задачник ОГЭ: задания 1–5

Тренажёр по практическим заданиям 1–5 ОГЭ-2025 по математике: 35 вариантов, 7 тем (шины, квартиры, участок, бумага, дороги, тарифы, печи).

- задания открываются по одному, ответы проверяются сразу;
- можно писать карандашами прямо на условии и в поле «Решение», есть ластик;
- кнопка «Отправить решения» собирает PDF, который можно отправить учителю.

Ответы и рисунки сохраняются только в браузере ученика.

Задания и ответы — из сборника А. Ю. Маракулина «ОГЭ-2025. Математика. 35 тренировочных работ».
